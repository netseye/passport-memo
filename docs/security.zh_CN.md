# 数据与安全

音频只驻留 RAM，由 Passport 编码后通过校验证书的 TLS 直接发送给火山。固件不保存音频文件，也不经 EE04 或自建服务器转发语音。云端数据处理以你使用的火山服务设置和条款为准。

Wi-Fi 凭据、ASR 凭据、备忘录和一个会话结束后的草稿保存在设备 `memo` NVS 分区。本构建未启用 Flash 加密；物理读取 Flash 或备份可能获取这些数据。凭据在刷机后自行配置，源码与分发镜像不内置账号密钥。

设置需要实际长按设备确定键。WPA2 热点及本地 HTTP 网页开放十分钟，使用本次开机生成的随机 8 位码。网页不回显已保存密钥，输入框留空会保留旧值。请使用设备当前显示的密码并在可信环境中设置，不要把管理页面暴露到公网。

EE04 同步通过 HMAC-SHA256 和短时一次性挑战验证写入与回执；使用局域网 HTTP，**不会加密局域网中的备忘录正文**。接收端需要手动配对，不会收到 ASR 密钥。

应用日志不输出凭据与转写内容，但分享前仍要检查底层日志，系统日志可能包含设备或网络标识。JSON 导出与 Flash 备份均属于私人数据。

漏洞请使用[私密报告](https://github.com/netseye/passport-memo/security/advisories/new)，不可用时先请求私密联系方式，不公开利用细节。另见[安全政策](../.github/SECURITY.zh_CN.md)。
