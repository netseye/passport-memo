# 验证记录

记录日期 **2026-09-11**。构建和主机测试可按[构建指南](build.zh_CN.md)复现，下面的硬件结果仅对应当天已安装的测试版本。

## 自动验证范围

- 全新 ESP-IDF 5.5.3 / ESP32-C3 编译，应用大小上限、分区表完整性及身份分区保护检查。
- UTF-8 限制、ASR 二进制封包、WebSocket 分片重组、连接 / 服务错误分类、Ogg CRC 与页测试。
- 原声缓存：标准 CRC32 向量、损坏与截断元数据、精确去除预跳过与补帧、120 秒边界及禁止移动 NVS / 缓存分区。
- 主机 libopus + 固件封装器 + FFmpeg：20 / 100 / 1,000 ms 音频的精确解码时长与 EOS。
- 真实 LVGL 界面在主机渲染，覆盖九种状态及 240 字文本。此前测得峰值 29,336 / 40,960 字节。
- EE04 主机测试：内容、图片、刷新逻辑，nonce 过期、防重放、计数回绕及签名字节。配套固件另行面向 XIAO ESP32-S3 编译。

本次公开源码构建：Passport 应用 **2,100,416 / 3,145,728 字节**，合并镜像 **2,165,952 字节**；EE04 应用 **1,769,744 字节**，静态 RAM **63,792 字节**。Git 版本字符串变化可能令大小略有变化。

## Passport 实机会话

硬件：ESP32-C3、8 MB Flash、无 PSRAM。凭据：旧版 App ID + Access Token。资源：`volc.bigasr.sauc.duration`。

| 指标 | 结果 |
| --- | --- |
| 会话 | 约 22 秒 |
| 最终结果 | `success=1`、`partial=0`，用户确认屏幕出现文字 |
| 编码帧数 | 1,097 |
| 编码耗时 | 平均 10,774 微秒，最大 20,960 微秒 |
| 采集栈最小剩余 | 40 KB 中剩余 19,604 字节 |
| ASR 连接后的堆 | 剩余 44,664 字节，最大连续块 15,872 字节 |

单帧最高编码耗时超过 20 ms，但该会话仍成功完成。短会话数据不能证明长期最坏情况性能或识别准确率。结束时出现过底层连接关闭警告，反复会话仍待验证。

原声回放及开源整理版已刷入 Passport，应用 / 分区表读回一致，身份和完整 `memo` 存储逐字节保持不变；开机无崩溃。实际回放听感与完整操作链仍在验收，下面的旧短会话指标不代表新增缓存写入的性能。CI 产物属于开发版本。

## 原声回放实测

新增缓存版本完成 **4.86 秒**录音和原声回放，ASR `success=1 / partial=0`，用户确认有声但初版音量偏小。244 个 Opus 帧（含补帧）缓存为 9,760 字节；回放输出 77,760 个采样，与实际录音时长一致。

- 编码平均 / 最大耗时：10,285 / 18,308 微秒；采集栈最小剩余 19,604 字节。
- 缓存写入最大耗时：4,807 微秒；ASR 连接后剩余堆 40,044 字节。
- 解码最大耗时：2,478 微秒；解码栈最小剩余 18,244 字节；正常结束无崩溃。
- 实际缓存另经主机 libopus 解码及 CRC 核对，未公开音频或文字内容。

后续音量修复将默认值调整为 85%，加入 +6 dB 回放增益与软限幅。完整 16 位 PCM 输入范围已通过单调、对称及溢出检查；最终听感仍需实机确认。

音量修复版刷入前后，原声缓存、身份和配置逐字节一致。重启后成功回放之前的 4.86 秒原声；随后又完成 6.6 秒、8.2 秒录音 / 识别 / 回放，均为 `success=1 / partial=0`，输出采样数准确。修复版最大解码耗时 3,496 微秒、解码栈最小剩余 18,244 字节、ASR 连接后最小剩余堆 39,680 字节。未观察到崩溃；用户尚未确认修复后的音量与失真。

## 首字加速版本实测

首字加速（`enable_accelerate_text=true / accelerate_score=10`）和 50 ms 界面检查版已刷入。应用校验通过，原声缓存、身份和配置逐字节保持不变；本地完整构建、主机测试及九种界面 / 240 字压力渲染通过，LVGL 峰值 29,336 字节。

一次 **32.42 秒**实机会话中，首条非空结果在第一批实际音频开始发送后 **1,766 ms** 返回，`final=0`，发生在录音结束前约 30 秒。累计 **36 次文字变化**均来自非最终包，最终 `success=1 / partial=0`，原声回放输出 518,720 个采样并正常结束。

该时间包含首批音频发送后的网络、云端处理与开头静音，不是从用户开口到 LCD 显示的测量。没有同条件旧版基线，不能据此量化提速百分比。用户对新旧首字速度及早期错字的主观对比仍待确认。

## 网页音频预览验证 — 2026-09-12

用户确认设备网页可以播放原声及拖动进度。更新后应用写入校验通过，既有原声缓存、备忘录存储与身份数据逐字节保持不变。本次验收未采集到设备传输耗时和 HTTP 栈峰值数据。

- ESP-IDF 全新构建及完整仓库 / 主机检查通过；未改变分区或持久化记录格式。
- 导出测试覆盖页面 CRC、未修改的 Opus 数据、精确 granule、120 秒边界、多余填充、音频损坏及读取 / 发送失败；单次分块不超过 1,360 字节。
- libopus / FFmpeg 校验 20 / 100 / 1,000 / 3,000 ms 的精确解码采样数，也包含无尾部填充的异常中断录音。
- 实际内联控制器测试覆盖请求头鉴权、按需获取、离线播放状态、401 / 404 / 服务端错误、不支持的格式、取消请求及 Blob 生命周期（含前进 / 后退缓存）。
- 内置浏览器成功解码并播放 3 秒合成音，跳转至约 1.5 秒；关闭本机 HTTP 服务后仍能继续播放。390 像素视口无横向溢出。浏览器显示总时长约 3.0065 秒，参考解码得到精确 3 秒。

多款手机兼容性、真实设备 120 秒传输、传输中断和同时退出设置尚待验证。图文预览及提交的演示音频均使用合成数据。
