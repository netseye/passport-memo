# 验证记录

记录日期 **2026-09-11**。构建和主机测试可按[构建指南](build.zh_CN.md)复现，下面的硬件结果仅对应当天已安装的测试版本。

## 自动验证范围

- 全新 ESP-IDF 5.5.3 / ESP32-C3 编译，应用大小上限、分区表完整性及身份分区保护检查。
- UTF-8 限制、ASR 二进制封包、WebSocket 分片重组、连接 / 服务错误分类、Ogg CRC 与页测试。
- 原声缓存：标准 CRC32 向量、损坏与截断元数据、精确去除预跳过与补帧、120 秒边界及禁止移动 NVS / 缓存分区。
- 主机 libopus + 固件封装器 + FFmpeg：20 / 100 / 1,000 ms 音频的精确解码时长与 EOS。
- 真实 LVGL 界面在主机渲染，覆盖九种状态及 240 字文本。此前测得峰值 29,336 / 40,960 字节。
- EE04 主机测试：内容、图片、刷新逻辑，nonce 过期、防重放、计数回绕及签名字节。配套固件另行面向 XIAO ESP32-S3 编译。

本次公开源码构建：Passport 应用 **2,089,792 / 3,145,728 字节**，合并镜像 **2,155,328 字节**；EE04 应用 **1,769,744 字节**，静态 RAM **63,792 字节**。Git 版本字符串变化可能令大小略有变化。

## Passport 实机会话

硬件：ESP32-C3、8 MB Flash、无 PSRAM。凭据：旧版 App ID + Access Token。资源：`volc.bigasr.sauc.duration`。

| 指标 | 结果 |
| --- | --- |
| 会话 | 约 22 秒 |
| 最终结果 | `success=1`、`partial=0`，用户确认屏幕出现文字 |
| 编码帧数 | 1,097 |
| 编码耗时 | 平均 10,774 微秒，最大 20,960 微秒 |
| 采集栈最小剩余 | 40 KB 中剩余 19,604 字节 |
| ASR 连接后的堆 | 剩余 44,664 字节，最大连续块 15,872 字节 |

单帧最高编码耗时超过 20 ms，但该会话仍成功完成。短会话数据不能证明长期最坏情况性能或识别准确率。结束时出现过底层连接关闭警告，反复会话仍待验证。

原声回放及开源整理版已刷入 Passport，应用 / 分区表读回一致，身份和完整 `memo` 存储逐字节保持不变；开机无崩溃。实际回放听感与完整操作链仍在验收，下面的旧短会话指标不代表新增缓存写入的性能。CI 产物属于开发版本。

## 原声回放实测

新增缓存版本完成 **4.86 秒**录音和原声回放，ASR `success=1 / partial=0`，用户确认有声但初版音量偏小。244 个 Opus 帧（含补帧）缓存为 9,760 字节；回放输出 77,760 个采样，与实际录音时长一致。

- 编码平均 / 最大耗时：10,285 / 18,308 微秒；采集栈最小剩余 19,604 字节。
- 缓存写入最大耗时：4,807 微秒；ASR 连接后剩余堆 40,044 字节。
- 解码最大耗时：2,478 微秒；解码栈最小剩余 18,244 字节；正常结束无崩溃。
- 实际缓存另经主机 libopus 解码及 CRC 核对，未公开音频或文字内容。

后续音量修复将默认值调整为 85%，加入 +6 dB 回放增益与软限幅。完整 16 位 PCM 输入范围已通过单调、对称及溢出检查；最终听感仍需实机确认。
