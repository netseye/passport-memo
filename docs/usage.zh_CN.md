# 图文使用手册

## 1. 打开设置

长按 **确定键约 1.5 秒**，进入 10 分钟设置窗口。用屏幕上的 **8 位数字**连接 **Passport-Memo** 热点，注意保留开头的 0。手动打开 **http://192.168.4.1**，网页管理密码也填这组数字。

![显示示例密码的设置界面](images/settings.png)

*设备界面代码的电脑渲染图。图中密码仅作示例，请以自己设备当前屏幕为准。*

手机提示“无互联网”时选择保持连接；不会自动弹出认证页。配置期间设备暂停连接路由器。同次开机内重新打开设置沿用密码，重启后会生成新密码。

## 2. 配置网络与火山识别

网页进入 **设备设置**，填写路由器的 2.4 GHz Wi-Fi 名称和密码。火山凭据可选新版 API Key，也可展开“旧版控制台凭据”填写 App ID + Access Token。已保存的 API Key 优先使用。

![使用示例数据的本地配置网页](images/portal-settings.png)

*真实网页配合本地演示数据的浏览器截图，不含实际凭据或设备数据。*

ASR 资源必须选择火山控制台实际开通且可用的产品：

| 网页选项 | 资源 ID |
| --- | --- |
| 模型 1.0 · 小时版 | `volc.bigasr.sauc.duration` |
| 模型 2.0 · 小时版 | `volc.seedasr.sauc.duration` |
| 模型 1.0 · 并发版 | `volc.bigasr.sauc.concurrent` |
| 模型 2.0 · 并发版 | `volc.seedasr.sauc.concurrent` |

成功实测使用 **模型 1.0 小时版 + 旧版凭据**。在设备上切换选项不会自动开通或购买火山资源。服务开通方式见[火山官方文档](https://docs.volcengine.com/docs/6561/1354869?lang=zh)。

密钥输入框留空会保留已保存的值。从 API Key 切换到旧版凭据时，先勾选清除识别凭据并保存，再填写旧版两项并保存，避免旧 API Key 继续优先生效。

保存后网页仍保持连接。按设备 **上键或确定键**退出设置，设备才会关闭热点并连接路由器；此时手机断开热点属于正常现象。请看设备首页底部，等联网和校时完成。

## 3. 录音、检查、保存

![录音与检查流程](images/recording-flow.png)

*真实界面代码渲染，文字为示例。*

按 **确定**开始，看到聆听页面再说话。再按 **确定**结束，等待最终文字。用 **上 / 下键**滚动检查，最后按一次 **确定**保存。

说话时前面的词和标点可能被修正。每次完整结果替换上一版文字，并跟随显示最新内容；检查页面回到顶部。当前是原始语音转写，没有额外的大模型改写或摘要。

## 4. 查看与整理

首页按上 / 下键进入历史；历史页用上 / 下键切换记录，长文字每 4.5 秒自动滚动 72 像素。确定键切换完成状态，长按上键回首页。

网页可以修改、删除、导出 JSON，目前不支持 JSON 导入。历史满 32 条时需先删除旧记录，不会静默覆盖。

## 保存方式与限制

每次最多 120 秒或 240 个 Unicode 字符，先达到哪项就结束。有文字的会话结束后，会在 Flash 留下一个未保存草稿；首页长按上键或重启可恢复，新产生的非空草稿会替换旧草稿。录音中突然断电可能丢失本次内容，因为不保存音频，草稿是在会话结束时写入的。

字库覆盖 GB2312 和部分标点，共 7,687 个字形。范围外的合法 Unicode 会保存在记录及导出中，但设备可能显示缺字。空闲一分钟会调暗背光，按键恢复；电量显示需要电量计可用。
