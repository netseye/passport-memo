# 故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 手机提示密码错误 / 无法加入 | 忘记已保存的 Passport-Memo 网络，重新输入设备当前 8 位密码，保留开头的 0；重启后密码会变。 |
| 手机提示无互联网 | 选择保持连接，热点仅供本地配置；手动打开 `http://192.168.4.1`。 |
| 保存配置后没变化 | 按设备上键或确定退出设置；关闭热点后才会连接路由器并校时。 |
| 退出后网页提示连接中断 | 正常现象：设置网页服务和热点已关闭。需要修改时长按确定并重新连接。 |
| 始终没有 Wi-Fi | 核对 2.4 GHz SSID 和路由器密码，不要填设备 8 位码；查看首页是否提示网络不存在或鉴权失败。 |
| 一直在校时 | 确认路由器可访问互联网且允许网络校时；TLS 需要正确时间。 |
| HTTP 401 / 403 | 核对凭据类型、App ID / Access Token 是否同属一个应用、服务是否开通、资源是否匹配。已保存的 API Key 优先于旧版凭据。 |
| 45000292 或额度错误 | 检查模型版本、小时 / 并发产品及可用额度，不凭这一号码断言唯一原因。成功实测使用 `volc.bigasr.sauc.duration`。 |
| WebSocket 已连接但识别失败 | HTTP 升级成功仅代表握手通过，后续仍可能因资源权限、额度或音频请求失败。 |
| 录音任务或 Opus 内存不足 | 从仓库默认配置用全新 SDK 配置编译，保留 C3 内存设置；报告中附脱敏堆与栈统计。 |
| 没文字 / 识别中断 | 看到聆听页面再说话，检查麦克风和网络，结束后检查已保留文字；不会自动重放音频。 |
| 前面的字被修改 / 到 240 字停止 | 中间结果会修正，当前每条最多 240 个 Unicode 字符。 |
| 双击没有回放 | 仅最近一段有音频；新录音会替换旧缓存。升级需同步刷入分区表。旧录音无法补回音频。 |
| 回放太轻或太响 | 播放中按上 / 下键调音量，默认 85%，每次 5%；提示音开关不影响回放。 |
| EE04 同步失败 | 核对同一局域网、接收端开关、IP 和配对码；历史页长按下键，选择“同步墨水屏”重试，本机记录会保留。 |

报告时提供提交版本、板卡、录音时长、屏幕错误和脱敏应用日志。请勿附密钥、SSID/密码、识别正文、NVS/Flash 备份或显示设置密码的截图。[提交问题](https://github.com/netseye/passport-memo/issues/new/choose)。
