# 更新记录

## 首字显示延迟优化 — 2026-09-11

- 开启中等强度首字加速，保留累计文字与二遍校正；早期文字可能继续修正。
- 界面状态检查间隔调整为 50 ms，跳过相同标签文字的重新分配和重绘。
- 增加首条文字返回时间及中间文字更新次数日志，不记录识别正文。

## 原声回放 — 2026-09-11

- 检查页或最近录音对应的历史页双击确定，通过内置扬声器回放原声。
- 回放进度、电平和音量显示；上下键调音量，确定停止。
- 默认回放音量 85%，可调至 100%；+6 dB 软件增益和软限幅改善小音量。
- 独立 Flash 缓存最近一段 Opus，最长 120 秒；保存后绑定记录，重启可恢复。
- 缓存完整性校验、精确去除编码延迟与补帧；新增分区不改变凭据和文字的 NVS 结构。
- 增加回放图文说明、损坏缓存与分区布局测试。

## 首次开源版本 — 2026-09-11

- 硬件端 16 kbps Opus/Ogg，直连火山流式 ASR。
- 中文像素界面、实时转写、检查保存、32 条历史、完成状态及一个未保存草稿。
- 临时本地设置网页、8 位设备密码、记录编辑 / 删除与 JSON 导出。
- 支持编码和 TLS 并行的 ESP32-C3 内存配置，保留 `cardid` 受保护布局。
- 区分连接与服务错误，避免日志泄露火山原始错误正文。
- 可选独立许可的 EE04 接收端，使用挑战 / HMAC 鉴权。
- 中英双语图文文档、独立源码结构及构建 / 主机 CI。
