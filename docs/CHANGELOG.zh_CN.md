# 更新记录

## 首次开源版本 — 2026-09-11

- 硬件端 16 kbps Opus/Ogg，直连火山流式 ASR。
- 中文像素界面、实时转写、检查保存、32 条历史、完成状态及一个未保存草稿。
- 临时本地设置网页、8 位设备密码、记录编辑 / 删除与 JSON 导出。
- 支持编码和 TLS 并行的 ESP32-C3 内存配置，保留 `cardid` 受保护布局。
- 区分连接与服务错误，避免日志泄露火山原始错误正文。
- 可选独立许可的 EE04 接收端，使用挑战 / HMAC 鉴权。
- 中英双语图文文档、独立源码结构及构建 / 主机 CI。
