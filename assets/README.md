# Assets

`fonts/` contains the pinned Unifont 17.0.05 source and OFL/copyright notices. `tools/build_memo_font.py` generates `main/memo_font_16.c`, named Memo Pixel 16, with GB2312 and selected punctuation. Regenerate it with `python3 tools/build_memo_font.py`.

Documentation screenshots live in `docs/images/`; use only demonstration fixtures. See [attributions](../docs/attributions.md).
